Grosmeister Relocation — готовий сайт

Структура:
  index.html
  css/style.css
  js/script.js      (логіка, дані країн, квіз)
  js/i18n.js        (переклади RU / EN, перемикач мов)
  img/logo.png
  img/og-cover.jpg  (картинка для превью в соцмережах, 1200x630)

Перед запуском:
  1) У index.html замініть https://example.com/img/og-cover.jpg на адресу вашого домену,
     наприклад https://ваш-домен.com/img/og-cover.jpg

Нові країни / зміни тексту:
  - Український текст додається в js/script.js, переклади RU та EN — у js/i18n.js
    у форматі  "укр. текст":["рос. переклад","англ. переклад"],
  - Перевірка, чого не вистачає: відкрийте сайт, F12 -> Console, виконайте I18N.missingAll()
    Список фраз без перекладу можна надіслати на переклад.
